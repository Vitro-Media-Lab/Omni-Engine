Prepared map data and source notices

The exact prepared map databases used by this release are freely available below. Each OSM map JSON is a derivative database from © OpenStreetMap contributors, distributed under ODbL 1.0. Retain the original OSM notices when redistributing or modifying these databases. This is the offered derivative data, without a sign-in or charge.

Elevation JSON and source manifests are separate terrain products with the actual contributing providers' terms; they are not assigned ODbL by this offer. Read the study notice for applicable copyright and licence references. Geographic clipping, simplification, architectural geometry preparation and elevation resampling have modified these sources.
